Bonne nouvelle : votre script **fonctionne correctement** pour l'exemple donné. Il affichera `Average: 87.6`.

Cependant, il y a un bug potentiel et quelques améliorations possibles.

### 🐛 Bug : division par zéro

C'est le problème principal. Si vous passez une liste vide, le script plante :

```python
calculate_average([])  # ZeroDivisionError: division by zero
```

**Correction :**

```python
def calculate_average(numbers):
    if not numbers:
        return 0  # ou lever une exception, selon votre besoin
    total = 0
    for i in range(len(numbers)):
        total += numbers[i]
    return total / len(numbers)
```

Si une liste vide est une erreur de programmation dans votre contexte, il vaut mieux lever une exception explicite :

```python
def calculate_average(numbers):
    if not numbers:
        raise ValueError("La liste ne peut pas être vide")
    ...
```

### ✨ Améliorations de style

**1. Itérez directement sur la liste** plutôt que sur les indices — c'est plus idiomatique en Python :

```python
for number in numbers:
    total += number
```

**2. Utilisez `sum()`**, qui est intégré et plus rapide :

```python
def calculate_average(numbers):
    if not numbers:
        raise ValueError("La liste ne peut pas être vide")
    return sum(numbers) / len(numbers)
```

**3. Alternative : le module `statistics`** de la bibliothèque standard :

```python
from statistics import mean

scores = [85, 92, 78, 95, 88]
print(f"Average: {mean(scores)}")
```

`mean()` lève déjà une `StatisticsError` sur une liste vide.

### Version finale recommandée

```python
def calculate_average(numbers):
    """Calcule la moyenne arithmétique d'une liste de nombres."""
    if not numbers:
        raise ValueError("La liste ne peut pas être vide")
    return sum(numbers) / len(numbers)


scores = [85, 92, 78, 95, 88]
print(f"Average: {calculate_average(scores)}")
```

### Points à noter

- En **Python 3**, `/` effectue une division flottante, donc pas de problème de troncature. (En Python 2, il aurait fallu utiliser `float(total) / len(numbers)`.)
- Vous pourriez aussi vouloir arrondir le résultat pour l'affichage : `f"Average: {calculate_average(scores):.2f}"` → `Average: 87.60`
